# Identity & Access Management (IAM) Hands-On Labs

Practical portfolio of Identity Governance, Hybrid Identity, and Automation labs built with **Microsoft Entra ID**, **Windows Server Active Directory**, **PowerShell**, and **Microsoft Graph API**.

## Hybrid Identity & Active Directory

- **[Lab 09 — AD DS & Microsoft Entra ID Hybrid Identity](Lab09-AD-DS-Hybrid-Identity/README.md)**: On-premises Windows Server 2025 AD DS/DNS deployment, Microsoft Entra Cloud Sync, and Microsoft Entra Hybrid Join validation.

## Entra ID Governance, Security & Federation

- **[Lab 01 — Privileged Identity Management (PIM)](Lab01-PIM-Least-Privilege/README.md)**: Just-in-Time (JIT) privileged role activation and least-privilege enforcement.
- **[Lab 02 — Google Federation & External Identities](Lab02-Google-Federation-External-Identities/README.md)**: External identity provider federation and B2B collaboration setup.
- **[Lab 03 — Dynamic Groups](Lab03-Dynamic-Groups/README.md)**: Rule-based automated group membership management.
- **[Lab 04 — Conditional Access](Lab04-Conditional%20Access/README.md)**: Zero Trust access policies enforcing MFA and risk/location conditions.
- **[Lab 05 — Self-Service Password Reset (SSPR)](Lab05-Self-Service-Password-Reset/README.md)**: End-user password recovery configuration and authentication methods.
- **[Lab 06 — Access Reviews](Lab06%20-%20Access%20Reviews/README.md)**: Periodic entitlement recertification to prevent privilege creep.
- **[Lab 07 — Access Packages](Lab07-Access-Packages/README.md)**: Entitlement Management resource bundling for structured onboarding.
- **[Lab 08 — Self-Service Access Packages with Approval](Lab08-Self-Service-Access-Packages-with-Approval/README.md)**: Multi-stage approval workflows for access requests.

## Identity Automation (PowerShell & Microsoft Graph)

- **[PowerShell MGraph Lab 01 — Bulk License Assignment](PowerShell-MGraph-Lab01-Bulk-License-Assignment/README.md)**: Automated Microsoft 365 / Entra license provisioning via Graph API.
- **[PowerShell MGraph Lab 02 — JML User Lifecycle Automation](PowerShell-MGraph-Lab02-JML-User-Lifecycle-Automation/README.md)**: End-to-end Joiner, Mover, Leaver (JML) identity lifecycle scripts using CSV ingestion and Microsoft Graph.
